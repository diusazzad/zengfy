## 🎯 কুইক রিভিশন রুলস
১. **ইন্টারভিউয়ার যদি জিজ্ঞেস করেন:** *"রেজিস্ট্রেশন ফর্মে কয়টি ফিল্ড রাখা উচিত?"*  
   ➔ উত্তর: **৩টি ফিল্ড (Name, Email, Password)** অথবা সোশ্যাল ওয়ান-ট্যাপ। কনভার্সন ড্রপ-অফ ম্যাথ ও প্রগ্রেসিভ প্রোফাইলিংয়ের ব্যাখ্যা দিন।
২. **ইন্টারভিউয়ার যদি জিজ্ঞেস করেন:** *"পাসওয়ার্ডের জন্য SHA-256 ব্যবহার করলে সমস্যা কী?"*  
   ➔ উত্তর: SHA-256 ফাস্ট হ্যাশিংয়ের জন্য বানানো। আধুনিক GPU প্রতি সেকেন্ডে শত কোটি SHA-256 হ্যাশ ব্রুট-ফোর্স করতে পারে। সর্বদা মেমোরি-হার্ড **Argon2id** ব্যবহার করা উচিত।
