# মডিউল ০৫: ফ্রন্টএন্ড আর্কিটেকচার ও মক টেস্টিং স্ট্র্যাটেজি (Frontend & Mock Auth)

> **ইন্টারভিউ ফোকাস:** UI-First ডেভেলপমেন্ট এবং ব্যাকএন্ড ছাড়া কীভাবে পূর্ণাঙ্গ এন্ড-টু-এন্ড টেস্ট করা যায়।

---

## ১. কেন React 19 + Tailwind CSS v4 স্ট্যাক?

1. **জিরো-রানটাইম সিএসএস:** Tailwind v4 নতুন অক্সাইড ইঞ্জিনে চলে, যা বান্ডেল সাইজ অত্যন্ত হালকা রাখে।
2. **মোবাইল এরগনোমিক্স (Mobile Ergonomics):** মোবাইলের জন্য টাচ টার্গেট অন্তত **৪৮x৪৮ পিক্সেল** হতে হয়।
3. **লাইভ পাসওয়ার্ড স্ট্রেন্থ এন্ট্রপি মিটার:** টাইপ করার সাথে সাথে কালার গ্রাডিয়েন্টে (লাল ➔ হলুদ ➔ সবুজ) রিয়েল-টাইম ফিডব্যাক প্রদর্শন।

---

## ২. মক অথেনটিকেশন ইঞ্জিন (Mock Auth Engine Architecture)

ব্যাকএন্ড রেডি হওয়ার আগ পর্যন্ত আমরা ব্রাউজারের `localStorage` ব্যবহার করে বাস্তবসম্মত সিমুলেশন করি:

```
[ ইউজার ফর্ম সাবমিট ]
         │
         ▼
[ Mock AuthService ]
         │
         ├──► ৮০০ms কৃত্রিম নেটওয়ার্ক ডিলে (বাটনে লোডিং স্পিনার টেস্ট)
         ├──► ডুপ্লিকেট ইমেইল চেক (পূর্বে সেভ করা থাকলে 409 কনফ্লিক্ট এরর)
         ├──► পাসওয়ার্ড স্ট্রেন্থ ভ্যালিডেশন
         └──► সাকসেস হলে লোকালস্টোরেজে ইউজার ডাটা সেভ
```

### সুবিশাল লাভ:
- ব্যাকএন্ড ছাড়াই লগইন, ভুল পাসওয়ার্ড মেসেজ, সফল সাইন-আপ এবং অন-স্ক্রিন ইমেইল ভেরিফিকেশন প্রিভিউ লাইভ টেস্ট করা যায়।
- পরবর্তীতে ব্যাকএন্ড তৈরি হলে শুধু `USE_MOCK = false` করে দিলে এটি রিয়েল এপিআইতে সুইচ করবে।
